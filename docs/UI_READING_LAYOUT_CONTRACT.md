# 代码阅读布局补充约定

2026-11-11，使用 frontend-design-direction。依据：用户提供的本地仓库截图，说明、提交信息占据编辑器上部，代码区偏小且无法调整。上一轮视觉收紧没有解决阅读空间的控制权。

目标是让用户进入本地仓库后直接阅读代码，必要时再看说明或报告。原生前端，不改变模型和审查逻辑。

- 仓库说明与快照范围默认收起，保留可展开入口；内置示例默认展示简短说明。两种来源分别记住选择。
- 左文件栏、右审查栏均可隐藏与恢复，拖动分隔线调宽；中间代码保留至少280px，防止被挤没。
- 工作区底部提供高度调节，支持指针及方向键，双击恢复默认尺寸。
- 专注模式临时隐藏两侧与说明，退出或Escape恢复原布局。原任务仍可运行，退出后能看轨迹。
- 只在本机存储尺寸与显示偏好；刷新恢复并按当前视口钳制，一键重置。手机端不显示不适用的列拖动柄。
- 1440x900、1024x768、390x844检查布局、长文件名、键盘与焦点。加载/空内容/错误/部分完成/成功/缺少密钥沿用既有可区分语义并执行回归。
