# 本地 Git 网页接入验证

日期：2026-10-25。本次将已有本地 Git 命令行读取接入原生网页。数据集不纳入审查，不扫描未入 Git 的本地数据目录。

## 使用流程

1. 启动 `start.cmd`，打开 http://127.0.0.1:8765。
2. 左侧切换「本地仓库」，路径默认填入相邻的 DKNet。
3. 点击「读取仓库」，选择目标提交，以及首次导入或两个提交对比。
4. 点击「预览代码变更」，查看文件、固定版本、加载大小与排除条目。
5. 点击「开始真实审查」，查看实时轨迹、代码证据和报告，下载 Markdown。

本地 Git 模式只提供真实审查，不提供假装审查仓库的脚本回放。内置示例的原有回放入口保留。

## 数据排除的实现边界

只枚举 Git 提交的树结构，按 blob 读取允许的代码与文本。不遍历工作区、不访问未提交数据、不下载 Git LFS 内容。

CSV、TSV、数组、常见医学影像/权重格式不读取；data、dataset、datasets、images、annotations、weights、checkpoints、outputs 等目录内的非 Python 文件也排除。目录中的 Python 加载代码仍属于可审查源代码。

有专门测试将超过原单文件预算的 CSV 提交进临时仓库，确认在读取内容和预算计算前已排除；未提交的数据标记也没有进入预览或模型输入。这与“直接把大文件截断后送给模型”不同。

## 新增接口与状态

| 接口 | 用途 |
| --- | --- |
| POST /api/git/inspect | 仓库规范路径、最近 30 个提交，读取本身不调用模型 |
| POST /api/git/preview | 加载代码快照，返回预览编号、代码视图和覆盖范围 |
| POST /api/git/reviews | 用预览编号创建真实审查，避免重新解析移动后的 HEAD |
| GET /api/reviews/{id}/input | 读取该任务原快照，页面恢复和证据定位不重新扫描仓库 |

预览内存最多保留 10 份，有效期 30 分钟；任务内存最多保留 30 份。重启服务后清空。任务保留自己的快照，即使预览被淘汰也可以查看原报告。恢复旧任务后，再次审查需要重新预览。

文件读取和删除文件支持范围沿用本地 Git 第一版限制；超出预算或遇到尚不支持的删除锚定时明确停止。Git 版本列表只显示最近 30 个提交。

## 浏览器验证为什么没有完成

已按 browser 插件流程连接内置浏览器，返回 `privileged native pipe bridge is not available; browser-client is not trusted`。在用户明确指定该插件后重试，仍返回相同错误。

随后尝试的 Windows/Edge 检查被工具停止，原因是无法可靠确认当前浏览器地址。遵照工具约束，停止了浏览器操作，没有修改信任配置或通过其他途径绕过。
