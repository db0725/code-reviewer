## 解释范围

这次复测没有出现结构反馈，Agent 完成率有所改善；输入 token 和耗时同时增加。它证明本批开发案例的输出更稳定，不能据此宣称更快、更省钱或发现所有缺陷。
这是一次组合改造前后的复测：接口从 Chat Completions JSON Mode 改为 DeepSeek Beta 严格函数调用（strict=true），同时引入 Pydantic 严格校验、step 传输包装和原生调用/结果配对。不能将全部变化单独归因于 Pydantic，也不能据此保证未来零格式错误。
两轮模型标识、案例及预算一致，但模型输出存在波动，接口与 Schema 也会改变输入 token 开销。位置命中不等同缺陷语义正确性，仍适用首次报告中 DK003、DK011 的契约边界。
结构化输出只约束结构；代码位置、原文、只读路径、去重、时限和执行白名单仍由原程序检查。没有自动降级、截取第一段 JSON 或通过忽略额外内容修复结果。
